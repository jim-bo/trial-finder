# Breast cancer: catalog index

Status checked against ClinicalTrials.gov on 2026-10-29: 1486 open cohorts in 1081 recruiting or not-yet-recruiting trials. Cohorts that fit more than one group appear in each.

Read **every** file for the patient's stage group and subtype, **and** every file in the "No subtype required" group for the same stage. If the stage is unclear (for example locally advanced, or recurrence after surgery), read both the Advanced and Early groups.
